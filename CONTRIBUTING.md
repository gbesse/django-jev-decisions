# Contributing

This repository contains an experimental community integration for Jev. Open an issue with the host version and a redacted reproduction. Follow the verification commands in the README before proposing a change. Do not commit secrets, real customer state or generated dependency directories. Add focused tests when changing decision contracts, host lifecycle or error behavior. Update `ai/CHANGELOG.md` with the purpose and important technical decisions. Keep examples explicitly synthetic and never describe an untested capability as verified.
