# Security and operational boundaries

This addon sends configured state to Typesafe when the real Jev provider is used. Host administrators own consent, credentials, authorization, retention, and downstream actions. A model judgment is not an authorization policy or a calibrated probability guarantee. Pin and evaluate your own models and thresholds before relying on them.

Do not include credentials or private payloads in public issues. Report a vulnerability through this repository's GitHub private vulnerability reporting when enabled; otherwise open a minimal issue requesting a private contact channel without exploit details. Provider and host failures must stay observable. This alpha has no security audit or support SLA.
